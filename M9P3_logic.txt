PROGRAM M9P3
1. Define the function that accepts inputs and returns the calculated result.
2. Initialize running total or counter to zero.
3. Set the continuation signal to Y.
4. While the signal is Y:
   a. Ask the user for the inputs.
   b. Call the function and store its returned result.
   c. Display the requested values.
   d. Update the running total or count.
   e. Ask whether to continue (Y) or stop (N).
5. Display the final total or count.
